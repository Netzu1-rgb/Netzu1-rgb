# Respuesta a las solicitudes de acceso

Plantilla para contestar cada solicitud que llega por correo durante la beta cerrada. Completá lo que está entre corchetes.

## Antes de responder
1. Elegí un código para la persona o el grupo. Que sea largo y difícil de adivinar (por ejemplo, tres palabras y un número).
2. Agregalo a `APP_ACCESS_CODES` en Vercel (separado por coma de los demás) y volvé a publicar.
3. Anotá en una lista tuya qué código le diste a quién, para poder darlo de baja después.

## Correo

**Asunto:** Tu acceso a NetAI

Hola, [nombre]:

Gracias por pedir acceso a NetAI. Ya podés entrar:

- Dirección: [https://tu-dominio/app]
- Tu código de acceso: [código]

Para instalarla en el teléfono:

- **Android (Chrome):** abrí la dirección, tocá el menú de los tres puntos y elegí "Instalar app" o "Agregar a la pantalla principal".
- **iPhone (Safari):** abrí la dirección, tocá el botón Compartir y elegí "Agregar a inicio".

Algunas cosas para saber:

- Tus registros se guardan en tu teléfono. Desde Ajustes podés descargar una copia.
- Estamos en beta: no se cobra y todas las funciones están habilitadas.
- El código es personal. Por favor, no lo compartas.
- NetAI no reemplaza la consulta con profesionales de la salud.

Si algo no funciona o tenés una idea para mejorarla, respondé este correo.

[Tu nombre]

## Para dar de baja un acceso
Quitá el código de `APP_ACCESS_CODES` en Vercel y volvé a publicar. Las sesiones abiertas con ese código se cierran.
