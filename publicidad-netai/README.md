# Publicidad para NetAI

Documentación para crear la publicidad de **NetAI** (plataforma de bienestar y nutrición consciente) con herramientas de IA y agentes. Basada en el código de la app (`netAI-codigo.zip`).

- [`marca-netai.md`](marca-netai.md): qué es NetAI, a quién habla, mensajes, tono, colores y límites éticos. **Léelo antes de generar cualquier anuncio.**
- [`herramientas.md`](herramientas.md): las herramientas de la lista, para qué sirve cada una en la publicidad y en qué orden usarlas.
- [`flujo-de-trabajo.md`](flujo-de-trabajo.md): flujo de trabajo propuesto, de la idea al anuncio publicado.
- [`netai-fit.md`](netai-fit.md): planificación de NetAI Fit, la app de gimnasio vinculada a NetAI: funciones, vínculo, beneficios cruzados y web en dos ventanas.
- [`rea-y-opciones-de-app.md`](rea-y-opciones-de-app.md): análisis de REA y comparación de opciones para construir la app (Capacitor, Expo, Flutter).
- [`skill-hostinger-web.md`](skill-hostinger-web.md): análisis de la skill de webs estáticas para Hostinger y su encaje con NetAI.
- [`../netai-web/`](../netai-web/README.md): la web estática con las dos apps para instalar.
- [`../netai-app/`](../netai-app/README.md): el código de la app NetAI (Next.js), con el rediseño.
- [`prompt-claude-code.md`](prompt-claude-code.md): prompt listo para pegar en una sesión nueva de Claude Code con todo este contexto.
- [`conectar-gemini.md`](conectar-gemini.md): plan para conectar NetAI a Google Gemini Flash (análisis de fotos real, cuotas, privacidad y costos).
- [`instalar-rea.md`](instalar-rea.md): cómo instalar REA como herramienta de Claude Code y reglas de uso para analizar apps de gimnasio.
- [`lanzamiento.md`](lanzamiento.md): lista para lanzar NetAI en internet: qué está hecho, qué falta y en qué orden (web primero, tiendas después).
- [`ficha-tiendas.md`](ficha-tiendas.md): textos para las fichas de Google Play y App Store, y qué declarar sobre los datos.
- [`respuesta-a-solicitudes.md`](respuesta-a-solicitudes.md): plantilla de correo para dar acceso a quien lo pide en la beta.
- [`estado-de-la-app.md`](estado-de-la-app.md): qué tiene la app hoy y qué le falta, en código y en diseño.

El repo ya incluye `youtube-shorts/`, una automatización de Shorts diarios. Se puede reutilizar su pipeline (`render.js`, `voz.js`, `upload.js`) para los vídeos de NetAI.
